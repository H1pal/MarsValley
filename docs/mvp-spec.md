# Mars Valley MVP 기능 명세

## 목적과 합의한 방향

란이 소멸한 지구를 목격한 뒤 화성으로 돌아와, 생존 가능성을 믿고 다시 떠나는 게임입니다. 기존 화성토를 개량한 공동 온실에서 농사짓고 주민과 식량을 나눕니다. 2D 탑다운 화면에서 키보드로 직접 이동합니다. 전투 대신 산소, 지형, 설비 사고, 모래폭풍을 극복합니다.

최종 목표는 화성 탈출입니다. 주민들과 동행할지 선택할 수 있으며 주민도 의사를 표현합니다. 란은 초반에 계획을 공개하고 주민은 동참·유보·반대로 나뉩니다. 식량 배분은 주민 논의를 거칩니다. 주민 위기에 개입할 수 있습니다. 주인공 사망 시 회차가 종료되고 처음부터 다시 시작합니다. 기본 경로는 30분 이내를 목표로 하며 선택적 구조와 이야기 진행에 따라 시간이 달라집니다. 30분은 게임 오버 제한이 아닙니다.

## 첫 구현의 범위

작은 연결 지도 하나에 공동 온실, 캡슐 잔해 지대, 폐쇄 설비 구역, 발사대를 배치합니다. 작물은 감자 한 종류, 주민은 선·홍 선생님·DJ 세 명입니다. 첫 수확까지 버틸 기존 수확물과 자란 작물이 있습니다. 토양 정화나 수질 시뮬레이션, 전투, 상점, 제작 트리, 온라인 기능은 제외합니다.

## 핵심 행동과 조건

| 기능 | 입력 및 선행 조건 | 결과와 실패 처리 |
| --- | --- | --- |
| 이동 | WASD 또는 방향키 | 벽·경작대·고정 설비를 통과하지 못함; 대각선 속도 정규화 |
| 농사 | 인접 경작대에서 E | 빈 칸 파종 → 급수 → 성장 → 수확; 수확물은 공동 창고로 이동 |
| 공동 노동 | 생존 중이며 작업 가능한 주민 | 일정 간격으로 급수·수확·재파종; 구조 중인 선은 작업 중단 |
| 식사 | Q 또는 식사 버튼, 공동 식량 1개 이상 | 허기 회복; 주민도 허기 기준에 따라 식사 |
| 수색 | 잔해에 접근해 E | 일정 시간 작업 후 부품 4개; 이동·대화·위험으로 작업 중단 가능; 중복 수령 불가 |
| 설비 안전화 | 차단 밸브에 접근해 E | 누출 구역의 피해 제거; 차단 전 경고와 위험 구역 표시 |
| 주민 구조 | 사고 발생 후 선에게 접근 | 부품 2개로 수리하거나 무료 대피 지원; 미대응 시 단계적 악화 후 사망 |
| 식량 논의 | 온실 게시판 | 주민들의 의견을 보고 공동 식사 우선 또는 균등 절약안 채택; 논의 중 시간 정지 |
| 동행 | 주민과 대화 | 각자의 조건 충족 시 초대/철회; 명시적으로 선택한 사람만 탑승 |
| 탈출선 복구 | 발사대에서 E, 충분한 부품 | 추진 장치와 생명 유지 장치를 각각 부품 4개로 복구 |
| 항해 비축 | 논의 완료 후 온실 게시판 | 공동 식량을 보존식으로 전환; 남길 식량 조건을 명시하고 적용 |
| 출발 | 두 장치 복구, 인당 보존식 2개 | 동행자와 남은 주민 확인 → 명시적 출발 → 열린 결말 |

## 임시 밸런스 수치

아래 수치는 구현과 검증을 위한 제안이며 사용자 확정 설정과 구분합니다.

- 체력·허기·산소는 0~100. 허기는 초당 0.12 감소, 0이면 체력이 초당 1 감소합니다. 식량 1개는 허기 35를 회복합니다.
- 실외 산소는 초당 0.45 감소하며 폭풍 중 2배입니다. 온실과 대피소에서 충전합니다. 산소 0이면 체력이 초당 5 감소합니다.
- 작물은 급수 후 90초에 성장, 수확당 식량 3개를 생산합니다. 종자는 수확 과정에서 확보하는 것으로 단순화합니다.
- 5분 주기 중 마지막 1분은 폭풍이며 30초 전부터 경고합니다. 폭풍은 이동과 산소 소모에 영향을 줍니다.
- 첫 사고는 플레이 2분 후, 구조 대응 여유는 4분입니다. 라디오와 HUD에서 지속적으로 경고합니다.
- 주민은 허기와 건강을 가지며 공동 식량 부족이 지속되면 사망할 수 있습니다. 규칙은 플레이어에게 공개합니다.
- 더 많은 주민과 탈출할수록 식량 준비가 필요하지만 고정 NPC가 없다고 탈출이 막히지 않습니다.

## 상태와 불변 조건

- 회차 상태는 진행 중 → 사망 또는 탈출로만 바뀝니다. 종료 상태에서는 이동, 소비, 수확, 부활을 할 수 없습니다.
- 자원은 음수가 되지 않습니다. 실패한 행동은 자원을 소비하지 않습니다. 인원과 물자는 발사 직전에 다시 검사합니다.
- 일시정지, 대화, 탭 비활성 상태에서는 시뮬레이션이 멈춥니다. 저장 시각과 현재 시각의 차이를 생존 시간에 더하지 않습니다.
- 위험은 진입 전 표시합니다. 가까운 상호작용만 허용합니다. 주민 사망을 숨기거나 조용히 회복시키지 않습니다.
- 회차 저장 실패를 사용자에게 알립니다. 손상되거나 다른 버전인 저장은 자동 덮어쓰기하지 않고 새 회차 선택을 기다립니다.
- 같은 브라우저의 여러 탭이 한 회차를 덮어쓰지 않도록 실행 잠금을 사용합니다.
- 재시작은 명시적 확인 후 수행하며 이전 자원과 관계를 이어받지 않습니다.

## 완료 기준

1. 새 회차에서 파종·급수·수확·식사·실외 이동·부품 수색을 직접 수행할 수 있습니다.
2. 혼자 탈출하는 경로와 주민을 구조하고 동행하는 경로가 모두 끝까지 연결됩니다.
3. 주민 의견과 식량 배분 결과, 위험 경고와 구조 기한을 화면에서 확인할 수 있습니다.
4. 굶주림/산소 고갈로 실제 사망하며 새로고침 후에도 사망이 유지됩니다.
5. 중단 후 이어하기, 대화/일시정지, 백그라운드 전환 중 생존 자원이 감소하지 않습니다.
6. 규칙 테스트, 린트, 정적 빌드가 통과하고 브라우저에서 실제 조작을 검증합니다.
7. 30분 목표의 실제 난이도는 별도 사용자 플레이테스트로 검증합니다. 자동 테스트 시간으로 실제 클리어 시간을 주장하지 않습니다.
