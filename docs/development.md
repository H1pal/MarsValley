# 개발 순서와 검증

## 기술 선택

의존성 없는 JavaScript ES 모듈과 Canvas 2D를 사용합니다. 작은 맵 한 장과 세 명의 주민에는 엔진·서버·DB가 필요하지 않습니다. HTML로 대화와 상태창을 제공하고 게임 규칙은 DOM과 분리합니다. 향후 맵·애니메이션·충돌 규모가 커지면 실제 복잡성을 근거로 엔진 도입을 검토합니다.

## 소유권

- `src/world.js`: 맵, 충돌, 좌표, 정적 상호작용 대상
- `src/game.js`: 회차 상태, 시간 진행, 자원, 주민, 행동·승패 조건
- `src/storage.js`: 저장 검증, 버전, 영구 사망 기록
- `src/map.js`: 월드 좌표 기반 SVG 미니맵·전체 지도, 폭풍 중 지도 사용 조건
- `src/render.js`: 란 추적 카메라, 보이는 타일과 월드 그림, 화면 기준 위험 효과
- `src/main.js`: 입력, 브라우저 루프, HTML 대화와 정보 모달, 일시정지, 저장 연결
- `index.html`, `src/style.css`: 전체 화면 플레이 영역, 화면에 고정된 HUD, 모달 레이아웃
- `scripts/server.js`: 로컬 정적 서버; 프로젝트 비공개 파일은 제공하지 않음
- `test/`: 규칙과 저장, 실제 시뮬레이션 경로 검증

## 구현 순서

1. 규칙과 공간: 이동, 농사, 생존, 위험을 순수 함수로 구현하고 테스트
2. 선택과 종료: 논의, 구조, 동행, 탈출, 영구 사망, 저장 검증
3. 플레이 화면: 브라우저 전체 영역에 지도 표시, 고정 HUD, 정보 모달, 대화, 위험 표시 연결
4. 실제 브라우저 확인: 시작, 이동, 상호작용, 일시정지, 이어하기, 종료 경로
5. 후속 플레이테스트: 신규 플레이어의 탈출 시간, 사망 원인, 선택 이해도 기록 후 수치 조정

## 수동 테스트 체크리스트

- 시작 소개에서 세 주민의 입장과 조작을 읽고 출발한다.
- WASD/방향키 이동, 벽 충돌, E 상호작용, Q 식사가 작동한다.
- 온실에서 파종·급수·수확하고 주민이 일하는 것을 확인한다.
- 실외 산소 감소와 안전 구역 충전을 확인한다.
- 수색 도중 이동하면 작업이 취소되고 부품을 중복 지급하지 않는다.
- 대화와 일시정지 중 수치가 멈추고 닫은 뒤 키가 눌린 채 남지 않는다.
- 탭을 숨기거나 창이 포커스를 잃으면 멈추며 명시적으로 재개한다.
- 사고 경고, 선의 위치, 구조 기한과 결과를 확인한다.
- 논의 후 항해 물자 전환, 초대/철회, 출발 직전 명단을 확인한다.
- 사망 후 새로고침해도 이어할 수 없고 새 회차는 초기 자원으로 시작한다.
- 두 탭에서 동시에 열면 두 번째 탭의 진행이 차단된다.
- 화면 크기를 바꿔도 게임 화면이 브라우저 표시 영역을 채우고 문서 스크롤이 생기지 않는다.
- 게임 바깥의 헤더, 사이드바, 자원 패널, 푸터가 없으며 모든 조작은 게임 위의 고정 HUD에 있다.
- 미션·내 정보·게임 정보 버튼은 각각 모달을 연다. Esc 또는 닫기 후 키보드 이동이 다시 작동한다.
- 정보 모달과 설정을 열어도 생존 시간·허기·산소가 감소하지 않고, 산소·허기·구조 경고와 기존 이벤트가 보존된다. 날씨 정보는 지도 모달에서 확인한다.
- 설정은 오른쪽 위의 작은 버튼으로 열고 조작 안내, 화면 효과 감소, 계속하기, 새 회차를 제공한다.
- 320px 세로 화면과 가로 화면에서도 고정 버튼이 겹치거나 화면 밖으로 나가지 않는다. 실제 이동은 키보드가 필요하다.

## UI 개편의 구현 범위

2026-10-20 첫 변경에서 전체 화면 UI를 구현했고, 이어진 후속 요청으로 아래 맵 확장과 카메라까지 구현했습니다. 스토리, 사건의 발생 조건·기한, 자원 소비, 탈출 및 사망 규칙은 유지합니다. 위치 안내 문구와 저장 좌표는 확장 지도에 맞게 갱신합니다.

Canvas는 브라우저 표시 영역 전체를 사용합니다. 브라우저 자체를 전체 화면 모드로 전환하는 기능은 아닙니다. 맵의 일부만 종횡비를 유지해 표시하며 란을 중심으로 카메라가 이동합니다. 맵 가장자리에서는 카메라를 제한해 지도 바깥 여백이 보이지 않게 합니다.

HUD는 Canvas와 분리된 HTML 오버레이로 화면 좌표에 고정합니다. 왼쪽 위에 미션·내 정보·게임 정보, 오른쪽 위에 원형 지도·생존 시간과 작은 설정, 하단에 행동·자원과 생존 게이지를 배치합니다. 일반 정보는 모달로 이동하되 산소 부족·굶주림·주민 구조 경고와 저장 오류는 플레이 화면에 계속 표시합니다.

기존 네이티브 `dialog`와 일시정지 처리를 재사용합니다. 미션 및 주민 상태의 DOM은 숨겨진 보관 영역과 모달 사이에서 이동하여 동일한 값을 보여줍니다. 모달을 닫으면 게임 Canvas에 포커스를 돌리고 눌린 이동 키를 비웁니다. 저장 오류의 진행 차단 규칙은 유지합니다.

`assets/images/template/tmp_screen01.png`, `tmp_screen02.png`, `tmp_screen03.png`는 화면 점유와 HUD 배치 참고에만 사용합니다. 해당 이미지나 잘라낸 부분을 게임 화면·아이콘·배포 파일에 삽입하지 않습니다.

## 확장 지도와 추적 카메라

맵을 32×20에서 64×40 타일로 확장했습니다. 타일은 32 월드 픽셀입니다. 온실의 내부 구조는 그대로 두고 `(4, 10)` 타일만큼 옮겼으며, 시작 위치는 `(11.5, 24.5)`입니다. 주요 지역과 위험 범위는 `src/world.js`가 소유하며 렌더러도 같은 값을 사용합니다.

| 지역 | 범위 (x, y, 가로, 세로; 타일) | 역할 |
| --- | --- | --- |
| 서쪽 공동 온실 | 5, 12, 12, 16 | 농사·논의·주민·산소 충전 |
| 북쪽 캡슐 잔해 지대 | 25, 4, 19, 13 | 주요 부품 수색과 동쪽 끝 통신기 |
| 중앙 O₂ 대피소 | 34, 20, 5, 4 | 원정 중 산소 충전 |
| 남동쪽 폐쇄 설비 | 48, 28, 12, 9 | 누출 차단과 선 구조 |
| 북동쪽 탈출소 | 54, 4, 8, 7 | 탈출선 복구와 출발 |

잔해 6개를 북쪽과 남쪽 탐사 경로에 분산합니다. 설비 누출 범위는 `(51, 30, 5, 5)`, 구조 중 선의 위치는 `(53.5, 32.5)`입니다. 균열에는 통과 가능한 우회로를 두고, 점선과 갈림길 표지가 지역 간 길을 안내합니다.

`cameraView`는 화면 크기와 란의 월드 좌표에서 카메라 위치를 계산합니다. 일반 화면에서는 타일당 48 CSS 픽셀을 사용하고, 큰 화면에서는 최대 30×20 타일까지만 보이도록 배율을 높입니다. DPR은 그리기 해상도에만 영향을 주며 같은 CSS 화면에서 보이는 영역은 같습니다. 카메라가 경계에 닿으면 란이 화면 중앙에서 벗어날 수 있습니다. 보이는 타일만 순회하며, 모래폭풍·누출 테두리와 HTML HUD는 화면 좌표에 고정합니다.

이동 속도, 산소 소비, 폭풍 주기, 구조 발생 120초·기한 240초는 기존 값을 유지합니다. 실제 이동과 시간 경과를 포함하는 자동 경로 검증으로 폭풍 중 수색 → 대피소 → 밸브 → 선 구조 → 주민 설득 → 전원 탈출을 확인합니다. 30분 이내 경로가 존재한다는 검증이며 신규 플레이어의 평균 클리어 시간을 보장하지는 않습니다.

### 기존 저장 기록 이행

상태 버전은 2로 올리되 기존 저장 키를 유지합니다. v1 기록은 먼저 기존 32×20 범위로 검증합니다. 온실 내부 위치는 온실과 함께 `(4, 10)`만큼 이동하고, 실외 위치는 새 온실 시작 지점으로 옮깁니다. 자원·생존 수치·경과 시간·사건 기한·동행·수색 완료 상태·회차 ID는 보존합니다. 불러오기 자체는 원본을 덮어쓰지 않으며 이어하기에서 정상 저장합니다. 이전 사망·탈출 기록도 이행하고, 사망 표식이 오래된 생존 저장보다 우선하는 규칙을 유지합니다.

## 첫 버전 이후

지금 필요한 것은 실제 플레이에 기반한 균형 조정과 도트 아트 교체입니다. 맵 확장과 카메라는 구현되었으며 지역 간 이동 경험은 후속 플레이테스트에서 조정합니다. 추가 작물, 복잡한 주민 AI, 다중 회의, 서버 저장, 모바일 조작은 현재 MVP 범위에 포함하지 않습니다. 실제 게임 화면의 접근성은 HTML 상태·대화·키보드 지원 수준이며, 지도 탐색의 완전한 비시각 대체는 별도 설계가 필요합니다.

## 지도 UI 구현과 검증 (2026-10-21)

`src/map.js`는 `world.js`의 지역·구조물·경로·지형 좌표를 SVG로 그립니다. 정적 지도는 초기화 시 만들고 플레이어 표식만 HUD 갱신 주기에 이동합니다. 원형 버튼과 전체 지도는 같은 렌더링 함수를 사용하며 전체 지도에만 지역 이름을 표시합니다. `canUseMap`으로 활성 회차이면서 폭풍이 아닌 조건을 판정하여 버튼 비활성화, 지도 내용 숨김, 열기 핸들러 모두에 적용합니다.

전체 지도는 기존 네이티브 dialog에 패널을 옮겨 표시합니다. 지도 모달 클래스는 매번 종류에 맞게 설정하여 다른 대화에 크기 변경이 남지 않습니다. 제목에 첫 포커스를 두어 내용 시작이 보이도록 하며, 닫으면 Canvas로 복귀합니다. 모달 중에는 시간과 이동이 정지합니다. 저장 형식·스토리·재해 주기·소모량은 변경하지 않습니다.

검증 항목: 맑음/예보/폭풍 시작/폭풍 종료 및 반복 주기의 지도 사용 조건, 이동 시 표식 갱신, 중앙 모달과 작은 화면 배치, 모달 중 시간 정지·Esc 복귀, 폭풍 중 지도 숨김과 종료 후 자동 복구. 폭풍 UI 검증은 기존 저장과 분리된 로컬 테스트 서버의 별도 회차를 사용합니다.

검증 결과: 린트·테스트 31개·빌드 통과. 브라우저에서 위치 표식 이동, 1280×720 및 375×667 배치, 모달 시간 정지·Esc 복귀, 폭풍 중 지도 숨김·버튼 차단과 종료 후 복구를 확인했습니다.
