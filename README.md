# Mars Valley · 마지막 온실

공동 온실에서 첫 자립 배양토를 만들고, 식량과 산소의 몫을 논의하며 화성에서 함께 정착하는 2D 탑다운 웹 생존 게임입니다. v1.5는 노동 기여, 동일 배급, 취약자의 필요가 충돌하는 상황을 다룹니다. 란이 사망하면 회차가 끝납니다.

## 실행

Node.js 22 이상이 필요합니다.

```sh
npm install
npm run dev
```

서버가 출력하는 로컬 주소를 브라우저에서 엽니다. 게임 자체는 외부 패키지나 서버 API를 사용하지 않습니다.

```sh
npm run check
```

ESLint, Node 테스트, 정적 배포 파일 생성을 순서대로 실행합니다. `dist/`는 정적 호스팅용 결과물이며 외부 게시·배포는 별도입니다.

## 플레이

- WASD/방향키 이동, E 농사·조사·대화, Q 내 배급으로 식사, Esc 일시정지입니다.
- 300초마다 기여도 중심·완전 균등·취약자 우선 중 예약한 배분안이 적용됩니다. Q와 산소 충전은 본인의 몫만 소비합니다. 미배정 재고로 추가 배급하거나 자신의 몫을 양도할 수 있습니다.
- 북쪽 잔해에서 의료 키트·필터·난방 코일, 다른 잔해에서 수리 자재·비상 물자를 수색합니다. 키트는 선·홍 선생님·온실 중 한 곳에만 씁니다. 선은 치료 후에도 노동하지 않습니다.
- 누출을 차단하고 급수·중앙 타워를 복구합니다. 여섯 번째 경작대의 감자를 비운 뒤 배양토를 조성하고 직접 급수·관찰합니다.
- 첫 흙, 정상 설비, 겨울 비축 8식과 최근 두 배급 주기·현재의 생존권을 점검합니다. 게시판에서 종료를 확정하면 생존 주민과 실제 지급 결과에 따라 네 결말 중 하나를 기록합니다.

맵은 기존 64×40 타일과 통로를 사용하고 카메라가 란을 추적합니다. HUD와 원형 미니맵은 화면에 고정됩니다. 상세 위치·날씨는 지도 모달에서 확인하며 폭풍 중에는 지도를 사용할 수 없습니다. 대화·정보·일시정지·백그라운드 상태에서는 생존 시간이 흐르지 않습니다.

## 저장

v1.5는 `mars-valley.run.v3`와 `mars-valley.terminal.v3`에 저장합니다. 이전 탈출 버전의 `.v1` 기록은 읽기 전용으로 보존하고, 새로운 정착 회차를 명시적으로 선택하도록 안내합니다. 탈출 성공을 정착 성공으로 변환하지 않습니다.

현재 회차의 종료와 영구 사망은 새로고침 후에도 유지됩니다. 같은 브라우저의 중복 탭은 공통 실행 잠금으로 차단합니다. 저장 오류가 나면 진행을 멈추고 원본을 자동 덮어쓰지 않습니다. 클라이언트 저장은 기기 간 동기화나 부정행위 방지 기능을 제공하지 않습니다.

## 구현과 검증 범위

규칙은 `src/game.js`, 맵과 접근 대상은 `src/world.js`, 저장 검증은 `src/storage.js`가 담당합니다. Canvas는 그리기, HTML은 고정 HUD와 대화·정보 모달을 담당합니다. 새 엔진·서버·DB·조작 키를 추가하지 않았습니다.

자동 테스트는 배급과 자원 보존, 세 의료품 용도, 직접 돌봄, 설비·흙 작업, 최근 두 주기와 현재의 권리 판정, 네 결말, 저장 분리·영구 사망을 확인합니다. 실제 이동과 생존 시간을 포함한 전원 정착 경로는 게임 시간 약 25분 4초에 도달합니다. 세 키트 사용처와 세 정책의 다른 조합은 직접 행동 경로로 검증합니다.

브라우저에서는 키보드 이동·E 회의·배급 예약·추가 배급·Q 식사·지도·모달 정지·재개·의료품 확인·최종 정착과 재로딩을 확인합니다. 최종 정착 UI 검증은 실제 규칙으로 만든 별도 로컬 테스트 회차를 사용합니다. 자동 경로 시간은 신규 플레이어의 실제 클리어 시간이나 난이도 평가를 대신하지 않습니다.

현재는 자체 도형 그래픽을 사용하는 프로토타입입니다. 최종 도트 아트, 음향, 자유 대화 AI, 온라인 기능과 모바일 이동 입력은 포함하지 않습니다.
