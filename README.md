# Mars Valley

공동 온실에서 식량을 기르고, 주변 폐허를 탐사하며, 누구와 화성을 떠날지 결정하는 웹 생존 게임의 첫 개발 버전입니다. 지구는 소멸했고 목적지의 생존 가능성은 확인되지 않았습니다. 주인공 란이 사망하면 회차가 끝납니다.

## 실행

Node.js 22 이상이 필요합니다.

```sh
npm install
npm run dev
```

브라우저에서 서버가 출력한 주소를 엽니다. 게임 자체는 외부 패키지나 서버 API를 사용하지 않습니다. 개발 서버는 로컬 주소에만 바인딩합니다.

```sh
npm run check
```

ESLint, Node 내장 테스트, 정적 배포 파일 생성을 순서대로 실행합니다. `dist/`는 정적 호스팅에 올릴 수 있습니다. 이번 작업은 로컬 개발이며 외부 배포를 포함하지 않습니다.

## 구현 원칙

- 게임 규칙은 `src/game.js`, 공간과 오브젝트는 `src/world.js`, 저장은 `src/storage.js`가 담당합니다.
- Canvas는 그림만 그립니다. HUD와 대화 선택지는 키보드로 사용할 수 있는 HTML입니다.
- 실행 중인 한 회차를 같은 브라우저에 저장합니다. 일시정지·백그라운드·종료 중에는 시간이 흐르지 않습니다.
- 사망/탈출 상태도 저장합니다. 사망한 회차를 이어하는 메뉴는 없습니다.
- 클라이언트 저장은 다른 기기와 동기화되지 않으며 개발자 도구나 저장 파일 변조를 막는 부정행위 방지 기능은 없습니다.
- 첫 버전은 원작 게임의 이미지·음악을 사용하지 않는 자체 도형 그래픽입니다. 타이밍과 난이도는 플레이테스트로 조정할 초깃값입니다.

## 현재 검증 범위

농사, 공동 노동, 식량 논의와 비축, 구조, 동행 조건, 환경 위험, 탈출, 저장을 연결한 기능 프로토타입입니다. 브라우저에서 혼자 탈출하는 경로를 직접 조작해 약 1분 44초의 게임 진행 시간으로 완료했습니다. 대화와 일시정지에 쓴 시간은 포함하지 않습니다. 실제 목표 분량의 난이도 조정과 장기 플레이 검증은 다음 단계입니다. 세 주민 동행과 사망·저장 규칙은 자동 테스트로 확인합니다.

논의는 두 가지 작성된 합의안을 확인하는 구조입니다. 자유로운 대화 AI나 동적인 다수결은 구현 범위가 아닙니다. 배경 음악, 사운드, 최종 도트 아트는 포함하지 않았습니다.
